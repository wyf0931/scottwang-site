这是我的个人站点，也是一个持续构建中的内容系统。

我不想把它只做成一个博客。文章、笔记、资源、项目、调研报告都会放在这里。它们的形态不一样，但来源最好保持简单。Markdown 和 MDX 对我来说够直接，也方便交给 Coding Agent 协助整理。

站点现在用 Next.js 和 TypeScript 实现，内容在构建时生成静态页面。它支持中文搜索、RSS、sitemap、robots.txt、llms.txt，也保留 Markdown 原文入口。人可以按页面阅读，Agent 也能更直接地获取站点信息。

这个项目公开，是因为它本身也是一份长期笔记。一个独立站点怎样组织内容，怎样处理 SEO 和 GEO，怎样让写作、项目展示和机器读取放在同一套流程里，这些都会继续在这里调整。

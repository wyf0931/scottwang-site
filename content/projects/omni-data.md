OmniData 是一个面向 Agent 工作流的数据服务站点。

当前提供：

- Web Search API
- Amazon 相关电商数据 API
- 公共分类数据 API

后续会继续扩展 Web Fetch，以及更多数据获取、清洗和处理能力。它的方向很明确：让 Agent 可以通过稳定的接口获得可复用的数据，而不是为每个任务临时拼接一套抓取逻辑。

项目暂不开源，公开内容主要介绍产品边界、数据能力和使用场景。

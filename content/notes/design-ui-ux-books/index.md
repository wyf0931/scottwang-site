[ytx-readings/design-ui-ux](https://github.com/ytx-readings/design-ui-ux) 是一个 GitHub 仓库，按主题分类整理了 60 多本设计类书籍的 PDF 和 EPUB，从色彩理论到用户体验，从 Figma 实操到设计心理学，覆盖面很全。下面按仓库的分组列一份清单，附带每本书的中文译名（如果有）和一句话简介。

### 色彩

- **Color Mixing Essentials** — 分三部分讲解数字绘画中的色彩混合技巧，面向插画和概念艺术初学者。
- **Color Theory**（色彩理论） — 从基础色彩原理出发，讲解色相、明度、饱和度之间的关系，适合绘画入门者。
- **Color Vision and Colorimetry: Theory and Applications** — 色彩视觉学和色度学的专业教材，涵盖 CIE 色彩系统、色差公式和工业应用。
- **Color Perception Mind and the Physical World** — 从认知科学和物理学交叉角度研究色彩感知，探讨人眼如何将物理光谱转化为颜色体验。
- **Color Works: Best Practices for Graphic Designers**（设计师色彩工作手册） — 平面设计师的色彩实践指南，收录大量真实项目案例，讲解如何在品牌、印刷和数字媒体中应用色彩。
- **Contemporary Color Theory and Use** — 现代色彩理论与应用，覆盖传统色彩学、数字色彩管理以及当代艺术中的色彩实践。
- **How to Learn Digital Painting** — 数字绘画学习指南，从色彩理论延伸到角色、道具、特效和背景的绘制方法。
- **Playing with Color** — 互动式色彩学习教材，分三部分通过练习让读者动手实验色彩搭配与视觉感知。
- **The Complete Guide for Choosing Colors** — 面向设计师的色彩选择完全指南，来自 Flux Academy 的在线课程配套教材。
- **The Designer's Dictionary of Color**（设计师色彩词典） — 以词条形式收录色彩术语和历史，从 Adobe 到 Zena，每条配有视觉示例和文化背景。
- **配色设计原理**（配色设计原理） — 中文配色设计书籍，通过大量案例讲解色彩搭配的基本规则和实际应用场景。

### 设计原则

- **Design by Nature**（自然设计） — 从自然界中的通用形式和数学模式出发，提取可用于平面设计的基本原则，如黄金比例、分形和对称。
- **Ruined by Design**（被设计毁掉的世界） — 探讨设计师如何在不经意间造成社会伤害，以及如何在商业压力下坚持负责任的设计伦理。
- **Tragic Design**（悲剧性设计） — 分析真实世界中因糟糕设计导致的灾难性后果，从医疗设备到投票系统，揭示设计的生死攸关面。
- **Universal Principles of Design**（通用设计法则） — 设计领域最重要的参考书之一，收录 125 条提升可用性、影响感知、增强吸引力的通用设计原则。
- **Universal Principles of UX** — Universal Principles of Design 的 UX 专注版，从用户体验角度重新解读设计原则。

### 设计工具 — Figma

- **Design in Figma** — Figma 设计入门教程，涵盖组件、样式、自动布局和协作流程。
- **Designing and Prototyping Interfaces with Figma** — 通过 Figma 创建交互原型的实战教程，从基础 UI 设计到高保真原型制作，有第一版和第二版。
- **Designing User Interfaces** — 系统讲解 UI 元素、设计原型方法，并全程使用 Figma 作为实践工具。
- **The Designer's Guide to Figma**（Figma 设计师指南） — Figma 进阶指南，深入讲解原型设计、团队协作、设计交付和工作流程优化。
- **UX Design with Figma** — 以设计思维为导向的 Figma UX 设计教程，强调以用户为中心的界面设计方法。

### 平面设计

- **Design Elements: A Graphic Style Manual**（设计元素：平面设计风格手册） — 平面设计的核心参考书，讲解排版、色彩、图像和版式的规则，以及何时该打破这些规则。
- **Design Elements: A Visual Communication Manual**（设计元素：视觉传达手册） — Timothy Samara 设计元素系列的第三版，从视觉传达角度重新组织设计基础原理。
- **Design Evolution: Theory into Practice**（设计演进） — 将设计理论转化为实际操作，展示基本设计原则在当代项目中的演变和应用。
- **Graphic Design Rules**（平面设计规则） — 以规则和反规则的形式讲解平面设计，每条规则后附带打破该规则的案例和时机分析。
- **Grid Systems in Graphic Design**（平面设计中的网格系统） — 网格系统的奠基之作，瑞士国际主义风格的代表作，系统讲解如何用网格构建秩序化的版面设计。

### 设计心理学

- **100 Things Every Designer Needs to Know About People**（设计师需要知道的人的100件事） — 用心理学研究解释人们如何看、读、记和行动，帮助设计师做出基于人性的设计决策。
- **Color Codes** — 跨学科研究色彩在现代哲学、绘画、建筑、文学、音乐和心理学中的理论角色。
- **Laws of UX** — 收集整理用户体验设计中最重要的心理学法则，如费茨定律、希克定律、雅各布定律等，配有可视化图解，有第一版和第二版。
- **设计心理学（1-4 册）**（设计心理学（1-4 册）） — 诺曼设计心理学全套四册中文版，涵盖日常物品设计、情感化设计、复杂系统设计和未来设计。
- **Design for a Better World** — 诺曼最新著作，从有意义、可持续和以人为本三个维度探讨设计如何应对全球性挑战。
- **Emotional Design**（情感化设计） — 解释为什么有些设计让人喜爱而有些让人厌恶，提出本能层、行为层和反思层三层情感设计模型。
- **Living with Complexity**（与复杂共处） — 挑战简单即好的迷思，论证复杂本身不是问题，设计的关键是让复杂变得可理解和管理。
- **The Design of Everyday Things**（设计心理学：日常的设计） — 设计领域的必读经典，通过门把手、开关等日常案例揭示可见性、反馈和映射等核心设计原则。
- **The Design of Future Things**（未来事物的设计） — 探讨自动化和智能设备的设计挑战，人与机器如何建立有效的沟通与协作关系。
- **Neuro Web Design: What Makes Them Click?**（神经 Web 设计） — 从神经科学角度分析网页设计，解释哪些视觉和交互元素会触发用户的潜意识决策。
- **设计师要懂心理学**（设计师要懂心理学） — 面向设计师的心理学读物，分四部分讲解感知、认知、情感和行为对设计的影响。

### UI 设计

- **Designing Interfaces**（界面设计模式） — UI 设计模式参考书，系统整理导航、表单、列表和数据展示等常见交互模式，有第二版和第三版。
- **Designing User Interfaces** — 来自 UI 设计平台 Umso 创始人的 UI 设计教程，注重实际工作中的设计决策和方法论。
- **Effective UI**（高效 UI） — 讲解如何在软件项目中构建优秀的用户体验，涉及流程、团队协作和设计评估。
- **Practical UI** — 实战型 UI 设计手册，用大量真实案例讲解布局、排版、色彩和组件设计的具体做法，有第一版和第二版。
- **Practical UI Patterns for Design Systems** — 面向设计系统的 UI 模式集合，提供可直接应用于组件库的交互设计模式和最佳实践。
- **Refactoring UI** — 专为开发者写的 UI 设计实用手册，用大量 before/after 对比展示如何通过简单调整提升界面品质。
- **The Ultimate UI Design Roadmap** — UI 设计学习路线图，从基础概念到高级技巧的系统化学习指南。
- **UI Design Principles** — UI 设计原则教程，从零开始讲解如何创建美观且可用的界面。
- **UI Design Systems Mastery** — 设计系统深度教程，分五部分从基础到进阶讲解组件库、设计 Token 和跨团队协作。
- **UI Pedia** — UI 设计百科全书，分三部分收录界面设计的概念、模式和案例。
- **Web UI Design for the Human Eye** — UX Pin 团队出品，从视觉感知角度分析网页 UI 的尺寸、间距、色彩和排版原则。

### UX 设计

- **App Design Apprentice** — 移动应用设计入门教程，分三部分从基础概念到完整项目实战。
- **Design for Developers** — 面向开发者的设计入门书，用开发者熟悉的思维框架讲解 UI/UX 设计基础知识。
- **Design for How People Think**（为思维而设计） — 基于认知心理学的研究，讲解如何将用户的心智模型转化为可用的信息架构和交互设计。
- **Designing UX Forms** — 专注表单 UX 设计，讲解如何设计不让人崩溃的表单流程、输入验证和错误处理。
- **Designing UX: Prototyping** — UX 原型设计实战指南，覆盖低保真到高保真原型的全流程方法论。
- **Designing with the Mind in Mind**（用心设计） — 从认知心理学角度讲解 UI 设计规则，涵盖注意力、记忆、感知、决策等核心认知过程。
- **DesignOps Handbook** — DesignOps 实践手册，讲解如何在组织中规模化设计团队的流程、工具和协作。
- **Design Systems Handbook**（设计系统手册） — 来自 InVision 团队的设计系统构建指南，讲解设计系统的创建、维护和跨团队推广。
- **Don't Make Me Think, Revisited**（点石成金） — Web 可用性领域最经典的小书，第三版更新了移动端内容，核心观点是别让用户思考。
- **Fixing Bad UX Designs** — 实战型 UX 修复指南，通过真实案例分析糟糕设计的问题所在并给出改进方案。
- **Principles of Product Design** — 产品设计原则教程，讲解如何将商业目标、技术约束和用户需求统一到产品设计中。
- **Simple and Usable**（简约至上） — 交互设计经典读物，提出核心功能优先、删除不必要功能、让用户快速上手等简化策略。
- **Storytelling in Design** — 讲解如何用故事化思维定义、设计和销售多设备产品，强调叙事在设计流程中的价值。
- **Strategic Writing for UX** — UX 文案写作指南，讲解如何通过文字推动用户参与、转化和留存，有第二版。
- **The Basics of UX Design** — UX 设计基础入门读物，覆盖用户体验设计的核心概念和方法论。
- **The Elements of User Experience**（用户体验要素） — UX 领域的奠基之作，提出用户体验五要素模型，从战略层到表现层逐级展开。
- **UX Fundamentals for Non-UX Professionals** — 面向非 UX 从业者的体验设计入门书，帮助产品经理、开发者和内容创作者理解 UX 基本原则。
- **UX/UI Design 2022** — UX/UI 设计入门到进阶指南，覆盖 Web 和移动应用的设计基础和最新技巧。
- **UX Writing** — UX 文案设计的学术与实践结合教程，讲解如何设计以用户为中心的界面文字内容。
- **这才是用户体验设计：人人都能看懂的产品设计书**（这才是用户体验设计：人人都能看懂的产品设计书） — 中文 UX 设计入门书，用通俗语言讲解产品设计的核心概念和实践方法。

### 导视设计

- **Signage and Wayfinding Design**（标识与导视设计） — 环境图形设计领域的权威参考，系统讲解标识系统的规划、设计和实施全流程。
- **Wayfinding Design Worldwide** — 全球导视设计案例集，收录来自世界各地的公共空间导视系统设计作品。

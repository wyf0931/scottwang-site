**Markdown** 是一种轻量标记语言，许多技术专业人士用它来创建和编辑技术文档。使用 Markdown 时，你在纯文本编辑器（例如 vi 或 Emacs）里写文本，插入特殊字符来创建标题、加粗、项目符号等等。例如，下面这个例子展示了一份用 Markdown 格式化的简单技术文档：

    ## bash 和 ksh

    **bash** 与一个较老的 shell 名为 **ksh** 非常相似。两个 shell 之间关键的
    *实用*区别如下：

    *  懂 bash 的人比懂 ksh 的人多，所以 bash 的问题比 ksh 的问题更容易得到帮助。

前面这份技术文档的渲染效果如下：
>
> ## bash 和 ksh
>
> **bash** 与一个较老的 shell 名为 **ksh** 非常相似。两个 shell 之间关键的
> *实用*区别如下：
>
> - 懂 bash 的人比懂 ksh 的人多，所以 bash 的问题比 ksh 的问题更容易得到帮助。

Markdown 解析器把 Markdown 文件转换成 HTML。浏览器随后可以把生成的 HTML 显示给读者。

我们建议通过学习以下教程之一来熟悉 Markdown：

- [www.markdowntutorial.com](https://www.markdowntutorial.com/)
- [掌握 Markdown](https://guides.github.com/features/mastering-markdown/)

技术写作中绝大多数句子应该用主动语态。本单元教你以下内容：

- 区分被动语态和主动语态。
- 把被动语态转换为主动语态，因为主动语态通常更清晰。

## 在简单句中区分主动语态和被动语态

在主动语态句子中，施动者作用于受动者。也就是说，主动语态句子遵循这个公式：

> 主动语态句子 = 施动者 + 动词 + 受动者

被动语态句子把这个公式反过来。也就是说，被动语态句子通常遵循以下公式：

> 被动语态句子 = 受动者 + 动词 + 施动者

### 主动语态示例

例如，这是一个简短的主动语态句子：

> 猫坐在垫子上。

- 施动者：猫
- 动词：坐
- 受动者：垫子

### 被动语态示例

相比之下，这是同一个句子的被动语态：

> 垫子被猫坐过。

- 受动者：垫子
- 被动动词：被坐过
- 施动者：猫

有些被动语态句子省略了施动者。例如：

> 垫子被坐过。

- 施动者：*未知*
- 被动动词：被坐过
- 受动者：垫子

是谁或什么坐在垫子上？猫？狗？霸王龙？读者只能猜测。技术文档中好的句子会明确谁对谁做了什么。

## 识别被动动词

被动动词通常遵循以下公式：

    被动动词 = be 的形式 + 过去分词动词

虽然上面的公式看起来吓人，但其实很简单：

- 被动动词中的 **be 的形式** 通常是以下词之一：
  - is/are
  - was/were
- **过去分词动词**通常是普通动词加上后缀 *ed*。例如，以下是过去分词动词：
  - interpreted（被解释）
  - generated（被生成）
  - formed（被形成）

不幸的是，有些过去分词动词是不规则的；也就是说，过去分词形式不以 *ed* 结尾。例如：

- sat（坐）
- known（知道）
- frozen（冻结）

把 be 的形式和过去分词结合起来就得到被动动词，例如：

- was interpreted
- is generated
- was formed
- is frozen

如果短语中含有施动者，介词通常会跟在被动动词后面。（这个介词往往是帮你发现被动语态的关键线索。）以下示例把被动动词和介词结合起来：

- was interpreted as
- is generated by
- was formed by
- is frozen by

### 祈使动词通常是主动的

很容易把以祈使动词开头的句子误判为被动。**祈使动词**是命令。有序列表中的许多条目以祈使动词开头。例如，下面列表中的 *Open* 和 *Set* 都是祈使动词：

1. 打开配置文件。
2. 把 `Frombus` 变量设为 `False`。

以祈使动词开头的句子通常是主动语态，即使它们没有明确提到施动者。相反，以祈使动词开头的句子*暗示*了一个施动者。这个隐含的施动者是**你**。

## 在更复杂的句子中区分主动语态和被动语态

许多句子包含多个动词，有些是主动的，有些是被动的。例如，下面这个句子包含两个动词，都是被动语态：

![句子图示：代码被 Python 解释，但代码被 C++ 编译。句子前半部分（代码被 Python 解释）是被动语态，受动者（代码）被施动者（Python）作用（被解释）。句子后半部分（代码被 C++ 编译）也是被动语态，受动者（代码）被施动者（C++）作用（被编译）。](https://developers.google.com/static/tech-writing/one/images/passive-passive.svg)

这是同一个句子，部分转换为主动语态：

![句子图示：Python 解释代码，但代码被 C++ 编译。句子前半部分（Python 解释代码）是主动语态，施动者（Python）作用于（解释）受动者（代码）。句子后半部分（代码被 C++ 编译）是被动语态，受动者（代码）被施动者（C++）作用（被编译）。](https://developers.google.com/static/tech-writing/one/images/active-passive.svg)

这是同一个句子，现在完全转换为主动语态：

![句子图示：Python 解释代码，但 C++ 编译代码。句子前半部分（Python 解释代码）是主动语态，施动者（Python）作用于（解释）受动者（代码）。句子后半部分（C++ 编译代码）也是主动语态，施动者（C++）作用于（编译）受动者（代码）。](https://developers.google.com/static/tech-writing/one/images/all-active.svg)

## 优先选择主动语态

大多数时候使用主动语态。少用被动语态。主动语态有以下优势：

- 大多数读者会把被动语态在脑海中转换成主动语态。为什么要让读者承受额外的处理时间？坚持主动语态，你就能让读者跳过预处理阶段，直接进入编译。
- 被动语态会掩盖你的想法，把句子颠倒过来。被动语态间接地报告动作。
- 有些被动语态句子完全省略施动者，迫使读者去猜测施动者的身份。
- 主动语态通常比被动语态短。

大胆一点——用主动语态。

### 科学研究报告（选学材料）

被动语态在某些科学研究报告中泛滥成灾。在这些研究报告中，实验者及其设备常常消失，导致被动句子以如下方式开头：

- 有人提出……
- 数据被获取……
- 统计被计算……
- 结果被评估……

我们知道谁对谁做了什么吗？不知道。被动语态会以某种方式让信息更客观吗？不会。

许多科学期刊已经接受主动语态。我们鼓励其余的期刊加入这场追求清晰的行列。

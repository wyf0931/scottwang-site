恭喜！你已经完成了技术写作（一）的课前学习部分，它覆盖了以下技术写作的基本原则：

| 章节 | 要点 |
|---|---|
| [用词](https://developers.google.com/tech-writing/one/words) |
| [用词](https://developers.google.com/tech-writing/one/words) | 定义新的或不熟悉的术语。 |
| [用词](https://developers.google.com/tech-writing/one/words) | 一致地使用术语。 |
| [用词](https://developers.google.com/tech-writing/one/words) | 避免歧义代词。 |
| [主动语态](https://developers.google.com/tech-writing/one/active-voice) |
| [主动语态](https://developers.google.com/tech-writing/one/active-voice) | 优先使用主动语态而非被动语态。 |
| [清晰的句子](https://developers.google.com/tech-writing/one/clear-sentences) |
| [清晰的句子](https://developers.google.com/tech-writing/one/clear-sentences) | 选择具体的动词而非模糊的动词。 |
| [清晰的句子](https://developers.google.com/tech-writing/one/clear-sentences) | 减少 *there is* 和 *there are*。 |
| [简短的句子](https://developers.google.com/tech-writing/one/short-sentences) |
| [简短的句子](https://developers.google.com/tech-writing/one/short-sentences) | 让每个句子聚焦一个观点。 |
| [简短的句子](https://developers.google.com/tech-writing/one/short-sentences) | 把一些长句子转换成列表。 |
| [简短的句子](https://developers.google.com/tech-writing/one/short-sentences) | 删掉不需要的词。 |
| [列表与表格](https://developers.google.com/tech-writing/one/lists-and-tables) |
| [列表与表格](https://developers.google.com/tech-writing/one/lists-and-tables) | 顺序重要时用有序列表，顺序无关时用无序列表。 |
| [列表与表格](https://developers.google.com/tech-writing/one/lists-and-tables) | 保持列表条目平行。 |
| [列表与表格](https://developers.google.com/tech-writing/one/lists-and-tables) | 以祈使动词开头有序列表的条目。 |
| [段落](https://developers.google.com/tech-writing/one/paragraphs) |
| [段落](https://developers.google.com/tech-writing/one/paragraphs) | 在第一句话确立段落的中心观点。 |
| [段落](https://developers.google.com/tech-writing/one/paragraphs) | 让每个段落聚焦一个主题。 |
| [目标读者](https://developers.google.com/tech-writing/one/audience) |
| [目标读者](https://developers.google.com/tech-writing/one/audience) | 确定目标读者需要学什么。 |
| [目标读者](https://developers.google.com/tech-writing/one/audience) | 让文档贴合目标读者。 |
| [文档结构](https://developers.google.com/tech-writing/one/documents) |
| [文档结构](https://developers.google.com/tech-writing/one/documents) | 以说明范围、目标读者和要点来开始一份文档。 |
| [文档结构](https://developers.google.com/tech-writing/one/documents) | 让文档瞄准目标读者。 |
| [标点符号](https://developers.google.com/tech-writing/one/documents) |
| [标点符号](https://developers.google.com/tech-writing/one/documents) | 用逗号制造句子中的短停顿，或分隔列表中的条目。 |
| [标点符号](https://developers.google.com/tech-writing/one/documents) | 用句号分隔不同的观点；用分号联合高度相关的观点。 |
| [标点符号](https://developers.google.com/tech-writing/one/documents) | 在引出列表的句子里用冒号代替句号。 |

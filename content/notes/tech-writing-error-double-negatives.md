**双重否定**是指包含两个否定词的句子或短语，例如：

- *不*，包括 *不能*、*不会* 等缩写形式
- *没有*

读者会觉得双重否定很难理解。（“等等，两个否定是不是抵消成了肯定？还是说错误消息的作者用两个否定来强调某件我不该做的事？”）

错误消息中有些双重否定非常明显：

不推荐
> 你不得不调用这个标志。

推荐
> 你必须调用这个标志。

另一些双重否定则更隐蔽。例如，下面这条错误消息中的 *防止* 和 *禁止* 都是否定词，导致消息令人困惑：

不推荐
> *pathname* 上的通用读取权限防止操作系统禁止访问。

推荐
> *pathname* 上的通用读取权限让任何人都能读取此文件。把访问权限开放给所有人是一个安全漏洞。关于如何限制读者，请参阅 *hyperlink*。

同样，也要避免“例外中的例外”。

不推荐
> App Engine 服务账号必须对该镜像拥有权限，除非有 Storage Object Admin 角色可用，否则 Storage Object Viewer 角色除外。

推荐
> App Engine 服务账号必须拥有以下角色之一：
>
> - Storage Object Admin
> - Storage Object Creator

# 原生 `<mark>` 文本高亮设计

## 目标

允许文章作者使用 HTML 原生 `<mark>` 标签标记值得强调的句子或短语，并在文章正文中显示背景色。高亮只改变背景色，不改变文本布局、字体、字号、行高、间距或段落结构。

## 使用方式

文章内容直接写标准 HTML 标签：

```mdx
这是一段文字，其中的 <mark>重要判断</mark> 需要被读者注意。
```

不增加 `Highlight` React 组件，也不增加 `==文字==` 等自定义 Markdown 语法。这样保持 HTML 语义与内容源的一致性，避免为已有平台能力重复造轮子。

## 实现边界

- 在现有文章正文范围 `.article-body` 下为 `mark` 增加样式。
- 背景色使用项目已有蓝色主题变量或其透明变体。
- 文本颜色继承正文颜色，不设置额外 padding、margin、border、font-weight 或 display 属性。
- 亮色和暗色主题都必须有可读的对比度。
- 依赖现有 `renderMdx` 管线，不新增解析插件或组件映射。
- 不改动 Markdown 下载内容；原生 `<mark>` 保持为内容源的一部分。

## 验证

- 增加渲染测试，确认 `renderMdx` 能保留原生 `<mark>` 标签及其文本。
- 运行 `npm run lint`、`npm run typecheck`、`npm test` 和 `npm run build`。
- 使用 `git diff --check` 检查格式。

## 不在范围内

- 多种高亮颜色或颜色属性。
- 高亮列表、金句索引或按高亮内容搜索。
- 编辑器工具栏或交互式选中文本功能。
- 自定义 `Highlight` 组件。
